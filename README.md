# 儿童歌谣拼图游戏

一个专为儿童设计的微信小程序拼图游戏，通过可爱的歌谣主题图片，帮助孩子们在游戏中培养观察力和动手能力。

## ? 游戏特色

- **多种难度选择**：简单(3x3)、中等(4x4)、困难(5x5)三种难度等级
- **可爱主题**：儿童歌谣相关的精美图片
- **智能打乱**：确保拼图可解的随机算法
- **成绩记录**：记录最佳完成时间和游戏统计
- **友好界面**：专为儿童设计的大按钮和鲜艳色彩
- **响应式设计**：适配不同屏幕尺寸

## ? 功能说明

### 主要功能
1. **首页**：游戏统计、快速开始、功能入口
2. **难度选择**：三种难度等级，显示最佳成绩
3. **拼图游戏**：核心游戏玩法，包含计时、计步、暂停等功能
4. **成绩系统**：记录最佳成绩，星级评分

### 游戏玩法
1. 选择合适的难度等级
2. 观察原图预览
3. 点击与空白块相邻的拼图块进行移动
4. 将所有拼图块移动到正确位置即可获胜

## ?? 技术实现

### 核心技术
- **微信小程序原生开发**
- **触摸事件处理**：实现拼图块的拖拽移动
- **Canvas绘图**：拼图块的图片裁剪和显示
- **本地存储**：游戏数据和成绩记录
- **动画效果**：流畅的过渡和反馈动画

### 关键算法
- **拼图打乱算法**：通过模拟移动确保拼图可解
- **碰撞检测**：判断拼图块是否可以移动
- **完成检测**：实时检查拼图是否完成

## ? 设计理念

### 色彩搭配
- **主色调**：温暖的粉红色系 (#FF6B6B)
- **背景色**：柔和的渐变粉色 (#FFE5E5 → #FFF5E5)
- **辅助色**：白色、浅灰色作为对比

### 交互设计
- **大按钮设计**：方便儿童点击
- **即时反馈**：触摸、移动都有视觉反馈
- **友好提示**：用表情符号和简单文字提示

## ? 自定义配置

### 修改图片资源
在 `pages/game/game.js` 中修改 `imageList` 数组：

```javascript
imageList: [
  'https://your-domain.com/image1.jpg',
  'https://your-domain.com/image2.jpg',
  // 添加更多图片URL
]
```

### 调整难度设置
在 `pages/game/game.js` 中修改网格大小：

```javascript
// 简单难度
if (difficulty === 1) {
  gridSize = 3
}
// 中等难度  
else if (difficulty === 2) {
  gridSize = 4
}
// 困难难度
else if (difficulty === 3) {
  gridSize = 5
}
```
