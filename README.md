# 儿童歌谣拼图 (uni-app版本)

## 项目介绍

这是一个基于uni-app开发的儿童歌谣拼图游戏，支持多端发布：
- 微信小程序
- App (iOS/Android)
- H5网页版
- 其他小程序平台

## 功能特点

### 🎮 游戏功能
- **多种童谣选择**：包含经典童谣"两只老虎"、"小星星"、"拔萝卜"等
- **三种难度等级**：简单(3x3)、中等(4x4)、困难(5x5)
- **背景音乐播放**：每个童谣配有相应的背景音乐
- **计时计步系统**：记录游戏时间和移动步数
- **最佳成绩保存**：保存各难度的最佳成绩

### 🎨 界面设计
- **儿童友好界面**：色彩鲜艳，操作简单
- **响应式设计**：适配不同屏幕尺寸
- **动画效果**：流畅的交互动画
- **原图预览**：游戏过程中可查看原图

### 🔧 技术特性
- **跨平台兼容**：一套代码多端运行
- **本地存储**：游戏数据本地保存
- **音效系统**：移动音效和背景音乐
- **模块化设计**：代码结构清晰

## 开发环境要求

- Node.js 14+
- HBuilderX 或 CLI 工具
- uni-app 开发框架

## 安装和运行

### 使用 HBuilderX
1. 克隆项目到本地
2. 使用 HBuilderX 打开项目
3. 选择运行平台（微信小程序/App/H5）
4. 点击运行按钮

### 使用 CLI
```bash
# 安装依赖
npm install

# 运行到微信小程序
npm run dev:mp-weixin

# 运行到App
npm run dev:app

# 运行到H5
npm run dev:h5
```

## 构建发布

### 微信小程序
```bash
npm run build:mp-weixin
```

### App
```bash
npm run build:app
```

### H5
```bash
npm run build:h5
```

## 游戏玩法

1. **选择童谣**：在童谣选择页面选择喜欢的童谣
2. **选择难度**：选择适合的难度等级
3. **开始拼图**：点击拼图块移动到空白位置
4. **完成拼图**：将所有拼图块排列成正确顺序
5. **查看成绩**：完成后显示用时和步数

## 技术实现

### 核心算法
- **拼图打乱算法**：通过模拟合法移动打乱拼图
- **移动验证**：检查拼图块是否可以移动
- **胜利判定**：检查所有拼图块是否在正确位置

### 状态管理
- **游戏状态**：计时、步数、难度等
- **数据持久化**：使用uni.storage保存游戏数据
- **音频控制**：背景音乐播放和静音控制

### UI组件
- **拼图组件**：动态生成拼图块
- **预览组件**：原图预览弹窗
- **成功弹窗**：游戏完成提示

## 开发说明

### 添加新童谣
1. 在`static/images/`添加图片
2. 在`static/audio/`添加音频
3. 在`pages/rhyme_select/rhyme_select.vue`中添加数据

### 自定义难度
修改`pages/game/game.vue`中的难度设置逻辑

### 样式定制
主要样式在`App.vue`和各页面的`<style>`标签中

## 注意事项

- 图片资源建议使用正方形
- 音频格式建议使用MP3
- 注意各平台的文件大小限制
- 测试时注意不同设备的兼容性
